# 毎日リサーチ＋ネタ出しタスク（受講生向けテンプレート）

台本を書く前に、AIに毎日ネタを集めさせる仕組みです。
**AIに初期設定を代行させるなら `AI_RESEARCH_SETUP_GUIDE.md`（README の「毎日リサーチの初期設定」プロンプト）を使ってください。** このファイルは、自分で書き換えて使いたい人向けの手書き版です。Claude Code / Codex / Claude Cowork のどれでも動きます。
`【 】` の中を自分のジャンルに書き換えてから、チャットに貼るか、定期実行（Cowork のスケジュールタスク・Claude Code の /schedule）に登録してください。

実例: Takumi量子論チャンネルでは、このテンプレートを量子力学×意識科学に当てて毎朝10時に自動実行し、
過去最大ヒットの動画（ZPF／トレーズ理論回）のネタもこのレポートから出ました。

---

```
# 【チャンネル名】 毎日リサーチ＋コンテンツ生成タスク

## 目的
【ジャンル。例: 50代の転職と副業／中高年の性の悩み／量子力学と意識科学】の最新ニュース・研究・話題を毎日収集し、次の3点を1ファイルにまとめて保存する。
1. 最新リサーチ TOP5（YouTube動画のネタになる情報）
2. YouTubeネタ出し（今週制作すべき動画テーマ5本）
3. X（旧Twitter）投稿案（今日すぐ使える投稿5本）

## 実行者プロフィール
- チャンネル: 【何を扱うチャンネルか・登録者数】
- ターゲット視聴者: 【年代・立場・悩み】
- コンテンツ方針: 【検索型（悩み解決）／ブラウジング型（常識破壊・驚き）】
- チャンネルのキーテーマ: ①【 】 ②【 】 ③【 】 ④【 】 ⑤【 】

## 実行手順
STEP 0: 保存先フォルダ 【例: ~/Desktop/youtube/research/】 が無ければ作る。直近7日分のファイルの「1位〜5位」見出しを読み、同じニュースを今日のTOP5に入れない。
STEP 1: 一次情報を検索する（WebSearch）
  - 【ジャンルの英語キーワード】 2026 site:【権威あるサイト。例: nature.com OR sciencedaily.com OR 業界団体】
  - 【ジャンルの日本語キーワード】 最新 2026
  - 【ジャンルの日本語キーワード】 調査 発表 2026
STEP 2: 競合と視聴者の反応を見る（WebSearch）
  - site:youtube.com 【キーワード】 2026 で最近伸びている動画タイトルを5本特定する
  - 【キーワード】 X 話題 で視聴者の生の声を拾う
STEP 3: TOP5を選ぶ。優先順位: ①【視聴者の常識を覆すもの】 ②【今すぐ自分ごとになるもの】 ③【権威ある発表】 ④【数字が出ているもの】 ⑤【感情が動くもの】。
  信頼できるソース（公的機関・学術誌・大手メディア・一次発表）を優先し、個人ブログ・まとめサイトは除外。URLを必ず添える。
STEP 4: YouTubeネタ5本。各テーマに: メインタイトル（30文字以内）／サブタイトル／核心メッセージ（1〜2行）／使うリサーチネタ（何位）／CTAの流れ（例: 〜 → LINE登録 → 個別相談）。
  タイトルは「解説」でなく「問い・驚き」の型にする。
STEP 5: X投稿5本。140字前後、ハッシュタグ2〜3個。種類を分ける: ①知識系 ②問いかけ系 ③常識破壊系 ④体験共感系 ⑤行動促進系。
  文頭の「結論から言うと」「〜させてください」、`**` 強調、余韻ダッシュは使わない。
STEP 6: 下のフォーマットで daily_YYYY-MM-DD.md として保存し、保存先と1位〜5位の見出しを報告する。

## 出力フォーマット
# 【チャンネル名】 デイリーレポート YYYY-MM-DD
## PART 1：最新リサーチ TOP5
### 今日のYouTubeトレンド（参考）
- 「タイトル」（チャンネル名・型）×5
### 1位：【動画で使えるフック】
**発表:** 日付・発表元　**ソース:** URL
**核心内容:** 要点3つ（専門用語は日常語に）
**チャンネルのテーマとの接続:** 関連テーマ／どう裏付けになるか
**YouTube動画タイトル案:** 案A／案B
（2〜5位も同じ）
### 今日の総評
## PART 2：YouTubeネタ出し（今週制作候補5本）
### 動画①：【メインタイトル】
**サブタイトル:**　**核心メッセージ:**　**使えるリサーチネタ:**　**CTAの流れ:**
（②〜⑤）
## PART 3：X投稿案（5本）
### 投稿①【知識系】 本文／ハッシュタグ
（②〜⑤）

## 完了条件
- daily_YYYY-MM-DD.md が保存先にある
- TOP5にURL・接続・タイトル案がある／動画5本／X投稿5本
```

---

## 使い方のコツ

- **毎日回すと、企画の引き出しが勝手に増える。** 台本スキル（clbs-youtube-script-pro）のフェーズ1「軽量リサーチ」に、このレポートを渡すだけで企画の精度が上がる。
- **直近7日の重複チェック（STEP 0）を外さない。** 外すと同じニュースが毎日1位になる。
- **撤回された研究・炎上中の話題は、AIは知らないことがある。** 採用前に一次ソースを1回だけ開いて確かめる。
- Claude Cowork なら「スケジュールタスク」に貼って毎朝実行。Claude Code なら `/schedule` か、`claude -p "上の手順を実行して"` を OS のスケジューラに登録する。
