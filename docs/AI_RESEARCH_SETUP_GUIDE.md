# AIエージェント向け 毎日リサーチの初期設定ガイド（clbs-youtube-script-pro v2）

この文書を読んでいるのは Claude Code / Codex などのAIエージェントである前提で書いている。
ユーザーは講座の受講生で、ターミナル操作に慣れていない。あなたの仕事は、ユーザーのジャンルを短いヒアリングで聞き取り、
そのジャンル専用の「毎日リサーチ」スキルを生成し、初回のレポートを1本作って見せ、毎日回す方法まで案内して終えることである。

前提: スキル `clbs-youtube-script-pro` が配置済みであること（未配置なら先に `docs/AI_SETUP_GUIDE.md` の STEP 1 を行う）。
以下、`<配置先>` は `~/.claude/skills/clbs-youtube-script-pro`（Codex は `~/.codex/skills/clbs-youtube-script-pro`）。

## 進め方の原則

1. **質問は1回に1つ。** 全部で6問。まとめて聞かない。答えが曖昧なら例を2つ出して選ばせる。
2. **答えを翻訳するのはあなたの仕事。** ユーザーは「検索語」や「発表元」を思いつけない。ジャンルからあなたが候補を作り、「これでいいですか」と確認する。
3. **ファイル作成・実行・検証は全部あなたがやる。** ユーザーに端末を触らせない。
4. **初回レポートを必ず1本作って見せる。** 設定だけで終わらせない。5〜10分かかることを先に伝える。
5. **キー・課金は不要。** WebSearch / WebFetch だけで動く。API キーの話を持ち出さない。
6. **各ステップの終わりに進捗を1行**（「✅ STEP n 完了 ／ 次: 〜」）。

## STEP 1 ヒアリング（1問ずつ）

| # | 聞くこと | 例の出し方 |
|---|---|---|
| 1 | チャンネル名（仮でよい）と、扱うジャンル | 「例: 50代の転職と副業／中高年の性の悩み／量子力学と意識」 |
| 2 | 誰に見てほしいか（年代・立場・いま困っていること） | 「例: 50〜60代の会社員。定年後の収入が不安」 |
| 3 | 動画の狙い | 「A 検索されている悩みに答える（検索型）／B おすすめに乗って驚かせる（ブラウジング型）／C 両方」 |
| 4 | 視聴者の常識をひっくり返したいテーマを3〜5個 | ジャンルからあなたが5個提案し、直してもらう |
| 5 | 動画を見た人に最後にしてほしいこと（CTA） | 「例: LINE登録／個別相談／メルマガ」 |
| 6 | 信頼できる情報源で思いつくもの（無ければ「おまかせ」でよい） | あなたが官公庁・学会・大手メディアから3〜5個提案 |

ヒアリング後、あなたが次を組み立てて1画面で確認を取る:
- 英語の検索語 2〜4個（英語の一次情報が薄いジャンルなら0個でよい）
- 日本語の検索語 3〜5個（「最新 2026」「調査 発表 2026」を付ける）
- 発表元 3〜5個
- ハッシュタグ 3個
- レポートの保存先（既定 `~/Desktop/youtube/research`。ユーザーが台本を作るフォルダがあればその中）
- スラッグ（英小文字・ハイフン。例 `tenshoku`）

## STEP 2 スキル生成（自分で）

```bash
python3 <配置先>/scripts/make_research_skill.py \
  --channel "<チャンネル名>" --slug <slug> \
  --genre "<ジャンル>" --target "<ターゲット>" --style search|browse|both \
  --themes "<テーマ1>,<テーマ2>,<テーマ3>,<テーマ4>,<テーマ5>" \
  --kw-en "<英語検索語,...>" --kw-ja "<日本語検索語,...>" \
  --sources "<発表元,...>" --cta "<CTAの流れ>" --hashtags "<#タグ #タグ #タグ>" \
  --out-dir "<保存先>"            # Codex なら --codex を追加
```

出力: `~/.claude/skills/<slug>-daily-research/SKILL.md` と `research_prompt.md`。
検証: SKILL.md の先頭 40 行を読み、ヒアリング内容が正しく入っているか確認する。誤りがあれば `--force` で作り直す。

## STEP 3 初回レポートを作る（自分で）

生成した SKILL.md の手順をそのまま実行する（WebSearch / WebFetch を実際に使う）。5〜10分。
完了したら、保存先のパスと TOP5 の見出し5行、動画①のタイトルを見せて、「このジャンルで合っていますか」と1問だけ聞く。
ズレていれば、テーマか検索語を直して STEP 2 を `--force` でやり直し、もう一度作る。

## STEP 4 毎日回す方法を案内する

ユーザーの環境に合わせて1つだけ案内する（全部は出さない）。

- **Claude Code を毎日開く人**: 「今日のリサーチ」とチャットに打てば動く。これが最も確実。
- **Claude Cowork を使っている人**: `research_prompt.md` の中身を Cowork のスケジュールタスクに貼り、毎朝の時刻を設定する。ファイルの開き方は `open -e <パス>` をあなたが実行して見せる。
- **完全自動にしたい人**: Claude Code なら `/schedule`（クラウドの定期実行）に「/<slug>-daily-research を実行して」を登録する。Claude Code の再起動後にスキルが `/` 一覧に出ることを先に確認する。

Claude Code のスキルは再起動しないと `/` 一覧に出ない。案内の最後に1回だけ「アプリを Cmd+Q で終了して開き直してください」と頼む。

## STEP 5 台本スキルとつなぐ

ユーザーが台本を作るフォルダの `CLAUDE.md`（Codex は `AGENTS.md`）に次を追記する（無ければ作る）:

```
## 毎日リサーチ
- レポートは <保存先>/daily_YYYY-MM-DD.md。台本の企画（clbs-youtube-script-pro フェーズ1）では、まず最新のレポートを読み、TOP5 とネタ5本を企画3案の素材にする
```

最後に最終表を出す:

| 項目 | 状態 |
|---|---|
| リサーチスキル | ✅ `~/.claude/skills/<slug>-daily-research` |
| 初回レポート | ✅ `<保存先>/daily_YYYY-MM-DD.md` |
| 毎日の回し方 | ✅ 〜（案内した方法） |
| 台本スキルとの接続 | ✅ `<path>/CLAUDE.md` |

一言添える:「明日からは『今日のリサーチ』と言えば、この形のレポートが毎回できます。企画を考えるときは、まずこれを読ませてください」。

## よくあるつまずき

| 症状 | 対処 |
|---|---|
| 検索結果が薄い・古い | 日本語検索語に「2026」「最新」「発表」を足す。英語の発表元（学会・業界誌）を1つ追加 |
| 毎日同じニュースが1位になる | STEP 0（直近7日の重複防止）が SKILL.md に残っているか確認 |
| ジャンルに一次情報が無い（体験談中心） | 発表元を「大手メディア・調査会社・Q&Aサイトの傾向」にし、TOP5 を「話題」ベースにする。テンプレはそのまま使える |
| `make_research_skill.py` が「既にあります」 | 作り直しなら `--force`、別チャンネルなら別 `--slug` |
| `/` 一覧に出ない | Claude Code を完全再起動。フォルダ直下に SKILL.md があるか確認 |
